# Hotwheel alarm clock!
Hello guys, welcome to my BLARE project!!!
AI DISCLAMER: AI was used in order to understand code, teach classes, and do a bit of struct work. C++ is not my forte, I code in java. I tried to use my own skills as much as possible but I am new so I had to use AI in order to utilize advanced concepts. 

I decided to do this project because one, its a cool mission, two, rest in peace insignia google home alarm clock, you served me well for 8 years.
In essence, my old alarm clock got bricked by google, and I needed a new one.

## What was my thought process? 
Well, at first I just build a run of the mill alarm clock from the tutorial, but as per regulations and also because I was bored i decided to make something unique.
As a kid, i really wanted a hot wheel garage, honestly still do. So I decided to make a hot wheel alarm clock!

## The Design
I based it off the tutorial at first, then used a DXF file i found to etch the logo into the cad. Any AMS printer should be able to handle this.
I also added a phone stand, this way i can maybe add a magsafe puck later and also use my phones standby mode.

## The PCB
This pcb is very similar to the tutorial, my apologies i just quite literally suck at PCB design. 
BUTTT, I did add something, a grounding plane! I realize my traces were going to be tight, and I learned how to make one from a previous project.
This way, i use WAYYY less traces.

## The code
C++ is not my language, im trying to learn, but its hard.
My main goal was to try and create 3 modes, like my CASIO watch!!!
In essence, it has a mode menu, where u can create and store up to 10 alarms (my watch can only do one so major upgrade)
AI was used in order to help me as i barely know c++
